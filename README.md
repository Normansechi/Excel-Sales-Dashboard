# Coffee Sales Dashboard (Microsoft Excel)

## Project Overview

This project analyzes a coffee sales dataset using Microsoft Excel. The objective was to transform raw sales data into an interactive dashboard that provides insights into sales performance and supports data-driven decision-making.

## Project Workflow

* Imported the coffee sales dataset.
* Cleaned and prepared the data by correcting inconsistencies and improving data quality.
* Built PivotTables to summarize key metrics.
* Created PivotCharts to visualize sales performance.
* Designed an interactive dashboard using Slicers and Timelines for dynamic filtering.
